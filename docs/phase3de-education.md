# Fase 3DE — educación y contexto

Se añaden diez familias de fichas para 20 músculos completos; no se crean fichas de cabezas o zonas inexistentes. Cada ficha conserva nombre, latín, región, descripción, función, acción, origen, inserción, inervación, relaciones y enlaces. Las 45 familias previas no se reescriben: quedan 55 familias musculares educativas.

Los textos son síntesis originales en español de las fuentes siguientes, consultadas durante esta fase. La geometría no se usa como fuente de función, inervación o fijaciones.

| Familia | Fuente principal | Criterio de alcance |
|---|---|---|
| Esternocleidomastoideo | [NCBI Bookshelf](https://www.ncbi.nlm.nih.gov/books/NBK532881/) | Músculo completo por lado; XI motor y contribución propioceptiva cervical. |

No se dibujan landmarks. |

El contexto utiliza IDs óseos curados y lateralidad ipsilateral o línea media: temporales `FMA52738/52739`, occipital `FMA52735`, mandíbula `FMA52748`, hioides `FMA52749`, esternón `FMA7485`, clavículas `FMA13322/13323`, C1–7 `FMA12519` a `FMA12525`, T1–3 `FMA9165/9187/9209`, primeras costillas `FMA7857/7987` y segundas `FMA7882/8012`.

El platisma muestra únicamente mandíbula como contexto óseo: su origen fascial no se sustituye por clavícula o costillas. Las fijaciones blandas permanecen en texto. No se calculan relaciones por distancia ni se añaden puntos geométricos de origen/inserción. Las pruebas verifican las 20 fichas, enlaces y contexto; no constituyen certificación clínica.
