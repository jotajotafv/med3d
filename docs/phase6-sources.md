La página de Anatomography conserva ShareAlike y remite a la declaración más reciente del archivo. Para los archivos 4.3 descargados desde Anatomography se mantiene explícitamente CC BY-SA 2.1 Japan, incluida `lungs.glb`. Ambas licencias permiten adaptación/redistribución con atribución; la pulmonar conserva también ShareAlike. [Aviso distribuido](../public/models/anatomy/respiratory/LICENSE.txt). No se incorpora geometría comercial, sin licencia, generada por IA ni otra fuente corporal. Z-Anatomy no fue necesario; no se rehizo su auditoría histórica.

Consultas oficiales: [descargas 4.0](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/download.html), [nota de versión 4.0](https://dbarchive.biosciencedbc.jp/data/bodyparts3d/LATEST/release_4.0_e.html), [manifiesto 4.3](https://lifesciencedb.jp/bp3d/get-info.cgi?version=4.3&cmd=concept-objfiles-list), `get-info.cgi` con `upload-all-list`, `title=obj2FMA`, `version=4.3`, y descarga selectiva `download.cgi`. El manifiesto recibido dice Data Version/Object set 4.3. Se filtró por FJ y se comprobaron las cabeceras nativas; no se asumió que cada fila de la lista global fuera parte de esa versión.
