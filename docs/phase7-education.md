# Fase 7 — fichas y contexto

`DigestiveInformation` / `digestive-education.ts` aportan nombre, latín, sistema, región, tipo, descripción, función, continuidad, partes, relaciones y fuentes a todas las nuevas unidades. El hígado incluye aporte vascular general. No se afirma inervación geométrica, inserciones ni fisiología derivada de la forma. Las fichas históricas se conservan.

Fuentes consultadas: OpenStax [organización](https://openstax.org/books/anatomy-and-physiology-2e/pages/23-1-overview-of-the-digestive-system), [boca/faringe/esófago](https://openstax.org/books/anatomy-and-physiology-2e/pages/23-3-the-mouth-pharynx-and-esophagus), [estómago](https://openstax.org/books/anatomy-and-physiology-2e/pages/23-4-the-stomach), [intestinos](https://openstax.org/books/anatomy-and-physiology-2e/pages/23-5-the-small-and-large-intestines), [órganos accesorios](https://openstax.org/books/anatomy-and-physiology-2e/pages/23-6-accessory-organs-in-digestion-the-liver-pancreas-and-gallbladder); DBCLS identifica la representación. La continuidad explicada es anatómica y no promete que cada conexión esté modelada.

| Estructura | Contexto explícito disponible |
|---|---|
| Esófago | Estómago, tráquea, laringe cartilaginosa, columna torácica |
| Lengua/glándulas | Mandíbula, hioides y estructuras orales incorporadas |
| Estómago | Esófago, duodeno, hígado, páncreas, tronco celíaco y arteria gástrica izquierda |
| Hígado | Vesícula, conductos, arteria hepática propia, vena porta y tres venas hepáticas existentes |
| Intestino | Segmentos contiguos disponibles; unión ileocecal sin renombrarla como ciego |
| Recto | Colon descendente, sacro y ambos coxales |
| Páncreas/conducto | Estómago, duodeno y su representación complementaria |

Las pruebas verifican que **cada ID contextual existe**. No se usa distancia 3D. No hay vasos mesentéricos ni nervios autonómicos adecuados en la cobertura histórica seleccionada para enlazarlos; no se inventan IDs. Bazo y ampliaciones de otros sistemas quedan fuera de alcance. El hígado se mantiene agregado porque la nomenclatura de sus piezas no justifica exponer segmentos clínicos. Las regiones gástricas/pancreáticas se explican sin cortar mallas.
