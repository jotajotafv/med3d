# Fase 8 · fichas y relaciones

Arquitectura compartida de órganos con 20 familias específicas en `internal-education.ts`; no reutiliza origen/inserción muscular ni campos vasculares. Cada órgano/componente muestra nombre, latín, sistema, región, tipo, descripción, función, relaciones, fuente y alcance geométrico. Se añaden secreción, organización o tipo linfoide sólo donde corresponde.

Referencias educativas: OpenStax, Anatomy and Physiology, capítulos [25.2](https://openstax.org/books/anatomy-and-physiology-2e/pages/25-2-gross-anatomy-of-urine-transport), [25.3](https://openstax.org/books/anatomy-and-physiology-2e/pages/25-3-gross-anatomy-of-the-kidney), [17.3](https://openstax.org/books/anatomy-and-physiology-2e/pages/17-3-the-pituitary-gland-and-hypothalamus), [17.4](https://openstax.org/books/anatomy-and-physiology-2e/pages/17-4-the-thyroid-gland), [17.5](https://openstax.org/books/anatomy-and-physiology-2e/pages/17-5-the-parathyroid-glands), [17.6](https://openstax.org/books/anatomy-and-physiology-2e/pages/17-6-the-adrenal-glands), [17.7](https://openstax.org/books/anatomy-and-physiology-2e/pages/17-7-the-pineal-gland), [21.1](https://openstax.org/books/anatomy-and-physiology-2e/pages/21-1-anatomy-of-the-lymphatic-and-immune-systems) y [27.1](https://openstax.org/books/anatomy-and-physiology/pages/27-1-anatomy-and-physiology-of-the-male-reproductive-system). Redacción breve propia sobre hechos anatómicos; no se copian figuras ni pasajes. DBCLS fundamenta las identidades geométricas, no se infiere fisiología de las formas.

Contexto mediante IDs explícitos: riñón → arteria/vena renal y uréter ipsilaterales; suprarrenal → riñón; hipófisis → hipotálamo/esfenoides; tiroides → laringe/tráquea/paratiroides; bazo → vasos esplénicos, estómago, páncreas y riñón izquierdo; timo → esternón/tráquea; próstata → vejiga/uretra/recto. Las fichas de componentes heredan relaciones apropiadas del órgano padre. Páncreas y testículos pueden mostrarse desde Endocrino conservando su sistema original.

Las relaciones son referencias anatómicas curadas, no inferencias por proximidad ni prueba de contacto entre superficies. No se crean ganglios, conexiones, microanatomía ni órganos femeninos en el cuerpo masculino. Las fichas históricas permanecen intactas.
