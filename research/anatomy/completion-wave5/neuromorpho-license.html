NeuroMorpho.Org is licensed under a Creative Commons Attribution 4.0 International License.

When using any material found on or downloaded from NeuroMorpho.Org in your
publication(s), please include each and all three citations listed below:

  1. The original paper(s) that describe the reconstructions, which appear(s) as a Pubmed link in the detailed metadata page of each reconstruction;
  2. The complete name: NeuroMorpho.Org (RRID:SCR_002145) and
  3. Tecuatl C, Ljungquist B, Ascoli GA (2024) Accelerating the continuous community sharing of digital neuromorphology data. FASEB Bioadv. 6(7):207-221. doi: 10.1096/fba.2024-00048

To reference a specific reconstruction (optional) you may also use the NeuroMorpho.Org ID of the neuron, in addition to the above three citations.

Data contributed to NeuroMorpho.Org

To cite NeuroMorpho.Org in a publication, as an online repository where your original data can be found, please choose from the following:

  1. At the time of writing your manuscript, if data has already been contributed to NeuroMorpho.Org, then state that the data "has been submitted to and will be available at NeuroMorpho.Org".
  2. At the time of writing your manuscript, if data is not yet contributed to NeuroMorpho.Org but will be in the near future then state that the data "will be submitted to NeuroMorpho.Org".
Programmatic access and usage of NeuroMorpho.Org

Programmatic access and usage of NeuroMorpho.Org is required to use the API for accessing meta data, and to use direct HTTP access of the .swc- or auxiliary files by accessing their direct URL. The URL to a data file may be deducted from archive and neuron name, as explained in the FAQ under "How can I programmatically access NeuroMorpho.Org?" . Programmatic access not using the API and/or direct links to data files, for example by calling one of the .jsp-pages using a script, is forbidden as it will result in degrading of the server performance, thereby affecting other users. Failure to comply will result in either automatic or manual permanent blocking. It is also highly recommended to identify the user agent of the program; you may be blocked for failure to do so, as we must block unnamed bots accessing NeuroMorpho.Org, in order to ensure the site availability. If you have been blocked unintentionally and want to be able to access NeuroMorpho.Org, please contact the administrator using the email below.
